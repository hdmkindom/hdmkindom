## 👨‍💻 About Me

我是一名数学与应用数学专业的学生，喜欢把抽象问题转化为可以运行、验证和复现的程序。

这个主页是我的技术陈列柜与实验记录，内容横跨机器人视觉、算法工程、形式化数学和自动定理证明。这里既有可以运行的系统，也有仍在演化的研究原型、数学笔记和小型实验。
